# Canvas Chess Board

Simple static project demonstrating a chess board rendered on an HTML5 canvas.

Contents

- `index.html` — page that shows the canvas
- `chess-board.js` — drawing/script logic

Preview

- Open `index.html` directly in a browser, or run a simple static server:

```
python -m http.server 8000
# then open http://localhost:8000 in your browser
```

How to upload this folder as its own GitHub repo

1. Change into this folder: `cd CHESS-BOARD`
2. Initialize git, commit, and push (see instructions below).
